What to check before ordering

Match the size and color

Save the exact variant and compare the seller’s measurements with a garment or pair you already own. For shoes, check whether the chart uses foot length or insole length.

Review available QC photos

If your agent offers warehouse QC photos, check the size label, color, stitching and any visible defects. Confirm the exchange window before approving shipment.

Estimate the full cost

Add the item price, domestic delivery, applicable agent fees and international shipping. Ask which shipping options use volumetric weight and check any applicable taxes or duties.
